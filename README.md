# Plataforma PI2 — CTeSP TPSI

Projeto integrado dos 5 grupos. Next.js (App Router) + TypeScript + Tailwind CSS + shadcn/ui.

## Arrancar

```bash
npm install
npm run dev
```

Abrir http://localhost:3000 e http://localhost:3000/design-system.
